# Unsupervised Anomaly Detection in Mars HiRISE Orbital Imagery

**NSSC 2026 — National Students' Space Challenge, IIT Kharagpur · Data Analytics**

An end-to-end **unsupervised** novelty-detection pipeline that finds injected "Genesis Outlier"
frames in ~10,400 grayscale 227×227 HiRISE crops, without labels, an outlier count, or any
pretrained model.

```
227×227 crop → custom Conv Autoencoder (from scratch) → 256-d latent
            → Isolation Forest → Novelty Score (higher = more anomalous)
            → statistically justified threshold → flagged crops
            → decoder reconstruction → per-pixel error heatmaps → geological hypotheses
```

## How to run

```bash
python -m venv .venv && .venv\Scripts\activate      # Windows
pip install -r requirements.txt
jupyter notebook mars_anomaly_pipeline.ipynb
```

Run cells top to bottom. Phase 1 trains **v1** (the model used for Phases 2–3); Phase 4 trains
**v2/v3** and the latent-dim sweep — set `RUN_ITERATIONS` / `DIM_SWEEP` there.

**Compute:** training is GPU-bound. On the CPU-only `torch` build a full run takes hours; either
install the CUDA wheel (`pip install torch --index-url https://download.pytorch.org/whl/cu121`) or
use Google Colab. `EPOCHS` at the top of the notebook auto-scales down on CPU for a quick smoke run.

## Design decisions (short)

* **Autoencoder, not VAE, for the baseline** — the KL prior pulls latent outliers toward the centre
  and weakens downstream separability (shown in Phase 4).
* **`LATENT_DIM = 256`** — 128 under-fits normal texture (noisy scores); 512 memorises rare
  structure and reconstructs anomalies too well (scores collapse); 256 is the empirical knee.
* **Loss = MSE + 0.15·(1−SSIM) + 0.10·GradL1** — all differentiable, all hand-built (no VGG/ResNet).
* **Threshold = Kneedle on the sorted novelty-score curve**, cross-checked against a robust
  `median + 3.5·MAD` fence and the KDE tail valley. Isolation-Forest scores are right-skewed and
  fail normality tests, so `μ + kσ` is reported only for reference. The `contamination` parameter is
  `"auto"` and is **not** used to set the final count.
* **Train/val split grouped by `source_image_id`** so near-duplicate crops from one scene don't leak.

## Result (summary)

The injected anomalies are **whole contaminated source observations**, not scattered crops:
`SRC_044, SRC_064, SRC_166` are 100 % flagged; `SRC_039, SRC_128, SRC_049, SRC_154, SRC_101,
SRC_119` are 70–90 %. Nearly all carry the metadata signature **latitude ± 90°, longitude 0°**
(every genuine scene is longitude 180°). Primary threshold `median + 3.5·MAD` on the v3 novelty
scores → `τ = 0.486` → **1 402 crops (13.5 %)**; high‑confidence core (98.5th pct) → **157 crops
(1.5 %)**. Full write‑up in [`report/REPORT.md`](report/REPORT.md); iteration journal in
[`CHANGELOG.md`](CHANGELOG.md).
